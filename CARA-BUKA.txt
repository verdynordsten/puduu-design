PUDUU  — CARA BUKA FILE DESAIN DI PEN.DEV
================================================

ISI PAKET INI:
- puduu.pen ........... file desain utama v5 LEDGER (5 layar HP 390px, buka di pen.dev)
- assets/ ............. WAJIB satu folder dengan puduu.pen (icon + mascot).
                        Jangan dipisah — kalau dipisah gambar jadi blank!
- gen_puduu_pen.py .... script generator (kalau mau revisi, edit ini lalu
                        jalankan: python3 gen_puduu_pen.py)
- preview-html/ ....... mockup HTML v5-ledger (buka di browser)
- preview/ ............ screenshot tiap layar buat intip cepat tanpa buka app

CARA BUKA (pilih satu):
A. Aplikasi pen.dev desktop:
   1. Extract ZIP ini ke satu folder (jangan pisahkan assets/).
   2. Buka pen.dev -> File -> Open -> pilih puduu.pen.
   3. Kalau kanvas kosong: tekan Ctrl+0 (zoom to fit), cek panel Layers.
B. Extension pen.dev di VS Code / IDE:
   1. Taruh folder ini di project.
   2. Klik kanan puduu.pen -> Open With pen.dev.

ISI 7 LAYAR:
  01 Today ..... timeline warna + brain-dump inbox + tombol Sort + I'm Stuck
  02 Focus ..... timer visual 32:10 + sub-steps + pause/+5/done
  03 Rescue .... maskot Puduu + 3 opsi thaw 2-menit + catatan free/Pro
  04 Ritual .... Switch Ritual: Close -> Breathe -> Begin + tombol mulai
  05 Grows ..... streak 5/7 tanpa-reset + trophies + mood check-in
  06 InboxSort . hasil "Sort for me" (rule-based, slot AI siap)
  07 Yours ..... paywall Pro $6.99 + nudges + sounds + text size + account

FONT: Fredoka (judul) + Nunito (isi) — gratis di Google Fonts.
Kalau belum install, tampilan tetap rapi tapi huruf fallback sistem.
