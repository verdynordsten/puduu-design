# Puduu 🦌 — Design Repo

English-first global visual ADHD planner. This repo = brand, tokens, mockups. App code lives in `../puduu-app`.

## Structure

- `tokens/` — design tokens (colors, type, spacing) as JSON + Dart-ready
- `mockups/` — clickable HTML prototypes (phone frame 390px), open in browser
- `brand/` — mascot direction, logo rules, copy voice
- `docs/` — design decisions, Tiimo teardown notes (patterns only, clean-room)

## Brand Pillars

1. Warm, not clinical (Tiimo = Scandinavian pastel-clinical; we = warm sunset playful)
2. Slow-steady-cute: pudu deer mascot, "small steps count" narrative
3. Shame-free: celebrate, never punish. No reset-to-zero streaks.

## Rules

- All copy in English. No emoji-as-icons (Lucide/Heroicons SVG only).
- Contrast 4.5:1 min, reduced-motion respected.
- Clean-room: patterns inspired by category, zero copied assets/copy from any competitor.
